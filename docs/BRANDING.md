# Houdini Brand Guidelines

## Visual direction

Houdini uses a dark, premium mining-console aesthetic inspired by the supplied brand references.

- Background: near-black / graphite
- Primary accent: Houdini gold
- Secondary accent: electric violet
- Primary text: warm white
- Typography: geometric sans-serif, uppercase labels, generous tracking
- Surfaces: subtle borders, glass/metal panels, restrained glow

## Logo usage

The Houdini top-hat/hash mark is the primary identity. Keep clear space around the mark and do not distort it.

## UI rules

1. Gold communicates primary actions, healthy mining and key performance metrics.
2. Violet is reserved for experimental/advanced pipeline states.
3. Red should only represent faults or unsafe hardware conditions.
4. Avoid dense gradients and excessive glow; the dashboard should remain readable in a HiveOS/X11 terminal environment.
5. Prefer compact telemetry cards over decorative widgets.
